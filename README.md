# gomoseko

Roblox-проект на [Rojo](https://rojo.space): подземный хаб (боевая яма с манекенами, храм «Комната порталов»,
торговые палатки) и интерфейс в стиле World of Warcraft (4 слота для колец, меню «Инвентарь» и «Магазин»).

Карта не хранится в репозитории как набор деталей: она **генерируется кодом** при старте сервера
(`src/server/BuildHub.server.luau`) в `Workspace.MainHub`. Весь проект остаётся текстовым и читаемым в диффах.

## Структура

```
default.project.json         # маппинг папок в DataModel
rokit.toml                   # версии инструментов (rojo, stylua)
src/
  shared/Config.luau         # константы хаба: размеры, цвета, порталы, настройки манекенов
  server/
    BuildHub.server.luau     # генератор карты, свет, SpawnLocation, манекены
    Dummies.server.luau      # урон по манекенам, HP-бар, респавн через 4 с
  client/
    Main.client.luau         # точка входа UI, горячие клавиши (1-4, I, B, Esc)
    ui/                      # Theme, RingBar, MicroMenu, Window, Inventory, Shop
```

В Studio проект попадает так:

| Папка            | Куда                                            |
| ---------------- | ----------------------------------------------- |
| `src/shared`     | `ReplicatedStorage.Shared`                      |
| `src/server`     | `ServerScriptService.Server`                    |
| `src/client`     | `StarterPlayer.StarterPlayerScripts.Client`     |

## Запуск

1. Установите [Rokit](https://github.com/rojo-rbx/rokit) и инструменты: `rokit install`.
2. Установите плагин Rojo в Studio (`rojo plugin install`) или с [Creator Store](https://create.roblox.com/store/asset/13916111004).
3. В корне репозитория: `rojo serve`, затем в Studio нажмите **Connect** в плагине Rojo.

Сборка файла места без Studio:

```
rojo build default.project.json -o build/gomoseko.rbxl
```

## Управление в игре

| Клавиша  | Действие                                  |
| -------- | ----------------------------------------- |
| `1`-`4`  | слоты для колец (пока только UI-заглушка) |
| `I`      | окно «Инвентарь» (пустая сетка 6x5)       |
| `B`      | окно «Магазин» (строки-заглушки)          |
| `Esc`    | закрыть открытые окна                     |

Манекены в яме получают урон от касания `Tool` и от клика (`ClickDetector`), респавн через 4 секунды.

## Важно при переходе с локального места

Если раньше хаб генерировался скриптом внутри Studio-места (например, `ServerScriptService.Script`),
**удалите старый скрипт** перед синхронизацией: иначе он при каждом запуске перезапишет карту.

## Палатки

Модель палатки грузится при старте сервера через `InsertService:LoadAsset` (ID в `Config.StallAssetId`):
берётся одна палатка из набора, уменьшается вдвое, из неё удаляются все скрипты и `Fire`, затем полосы
перекрашиваются в жёлтый, синий, красный и зелёный. Если загрузка не удалась, строятся процедурные палатки.
