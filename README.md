# gomoseko

A [Rojo](https://rojo.space) Roblox project: an underground hub (combat pit with training dummies, the "Portal Room"
temple, market stalls) with a World of Warcraft-style interface (player and target frames with HP/mana, 4 ring slots,
Inventory and Shop windows). The first ring is **Arc Lightning**.

The map is not stored in the repository as parts: it is **generated by code** when the server starts
(`src/server/BuildHub.server.luau`) into `Workspace.MainHub`. The whole project stays text-only and diff-friendly.

## Structure

```
default.project.json         # maps folders into the DataModel
rokit.toml                   # tool versions (rojo, stylua)
src/
  shared/
    Config.luau              # hub constants: sizes, colours, portals, lighting, dummies
    Types.luau               # shared types (skill, ring, inventory state, lightning hop)
    Fonts.luau               # built-in Roblox fonts (FontFace) + preload
    Sounds.luau              # sound registry (IDs from Assets.luau generated by Asphalt, or Sounds.Manual)
    Assets.luau              # generated by `asphalt sync` (placeholder until assets are uploaded)
    Remotes.luau             # remotes: created by the server (init), fetched by the client (get)
    Configs/
      CombatConfig.luau      # Enemy tag, mana, validation tolerances, Tab-target range
      Skills/ArcLightningConfig.luau  # damage, radii, delay, cooldown, mana, lightning colours/sound
      Rings/RingsConfig.luau # ring pool: quality, "1 in N" rarity, passive stats, skills
      GachaConfig.luau       # summon cost, free roll, luck cap, essence, rewards, starting currencies
      MonetizationConfig.luau # Robux products and game passes (IDs to fill in)
    Combat/ChainSearch.luau  # pure next-target search for chain skills (no Roblox API)
    Combat/Progression.luau  # levels and XP (pure math)
    Combat/CooldownMath.luau # radial cooldown geometry (pure math)
    Gacha/GachaMath.luau     # exact summon probabilities, rolling and odds formatting (pure math)
  server/
    BuildHub.server.luau     # map generator, SpawnLocation, dummies (Enemy tag)
    Hub/Atmosphere.luau      # lighting, sky, post effects, moonlight shaft (values: Config.Lighting)
    Hub/Decor.luau           # inlay, wood trim, banners, lamps, crates/barrels, moss, crystals, fireflies
    Dummies.server.luau      # damage to dummies (Tool touch), HP bar, respawn after 4 s
    Main.server.luau         # bootstrap: creates remotes and starts the services
    Services/
      DataService.luau         # player profile in DataStore (session lock, autosave, BindToClose)
      CurrencyService.luau     # Gold / Summon Crystals / Ring Essence (attributes on Player)
      StatsService.luau        # passive bonuses of equipped rings (Bonus_* attributes)
      PlayerStatsService.luau  # player mana and XP (attributes Mana/MaxMana, Level/XP/XPToNext)
      InventoryService.luau    # ring inventory and equipped slots (server is the source of truth)
      GachaService.luau        # ring summon: rolls, luck, free roll, announcements
      MonetizationService.luau # ProcessReceipt, game passes, PolicyService (paid random items)
      CombatService.luau       # casting (CastTime), validation, chain jumps, damage, XP, visuals
  client/
    Main.client.luau         # entry point: UI, controllers, hotkeys (1-4, Q, Tab, I, B, Esc)
    Controllers/             # InventoryController, TargetController, SkillController, GachaController
    VFX/LightningRenderer.luau  # lightning rendering (Beam + zigzag, fade, cleanup)
    VFX/DamageNumbers.luau   # floating damage numbers above targets
    VFX/TorchFlicker.luau    # client-side flicker of torches and lanterns (tag "Torch")
    VFX/Sfx.luau             # sound playback (SFX group, pitch jitter, limit)
    ui/                      # WoW style without external images, everything is drawn in code:
                             #   Theme (palette, item quality), Chrome (gold frames, slots, glow),
                             #   RingBar, RadialCooldown, RingIcon, Glyphs, Window, Inventory, Character, Drag,
                             #   ModelView, Shop (Store), Summon (Gacha), CurrencyBar, MicroMenu,
                             #   PlayerFrame, TargetFrame, Portrait (ViewportFrame), StatusBar, XpBar, CastBar,
                             #   Tooltip, Notice
assets/audio/                # Arc Lightning sounds (.ogg), generated by tools/make_audio.py
tools/make_audio.py          # synthesizes the sounds (python3 + ffmpeg, no extra libraries)
tools/tests/                 # pure-Luau checks (GachaMath): luau tools/tests/gacha_math_test.luau
asphalt.toml                 # asset upload config (Asphalt)
```

## Getting started

1. Install [Rokit](https://github.com/rojo-rbx/rokit) and the tools: `rokit install`.
2. Install the Rojo plugin in Studio (`rojo plugin install`) or from the [Creator Store](https://create.roblox.com/store/asset/13916111004).
3. In the repository root run `rojo serve`, then click **Connect** in the Rojo plugin in Studio.

Build a place file without Studio:

```
rojo build default.project.json -o build/gomoseko.rbxl
```

## Controls

| Key / action              | What it does                                                                  |
| ------------------------- | ----------------------------------------------------------------------------- |
| `1`-`4`                   | use the ring in that slot (clicking the slot does the same)                   |
| `Q`                       | quick-cast Arc Lightning (while the ring is equipped)                         |
| Left click on an enemy    | select a target (outline + target frame); click empty space / `Esc` to clear  |
| `Tab` / `Shift+Tab`       | on-screen enemies within 100 studs: nearest, then cycle forward / backward    |
| `C`                       | Character window: model, 4 ring slots, stats (drag rings in, swap, drag out)  |
| `I`                       | Inventory: right-click a ring to equip/unequip, or drag it onto a ring slot   |
| Right click on a slot     | unequip the ring                                                              |
| `G`                       | Ring Summon window (Gacha): summon ×1 / ×10, free roll, odds, auto roll       |
| `B`                       | Store window (Robux: Summon Crystals, luck potions, passes)                   |
| `Esc`                     | close open windows and clear the target                                       |

**Arc Lightning.** The lightning hits a target (the selected one or, with no target, the nearest enemy within cast
range), then jumps to the nearest enemies within the bounce radius, never hitting the same enemy twice in a chain.
Only models with the `Enemy` tag (CollectionService) and a living `Humanoid` can be hit; the dummies in the pit
get the tag when the map is generated. Damage, mana, cooldown and distance are validated on the server
(`CombatService`); the client only renders the lightning. Balance lives in `Configs/Skills/ArcLightningConfig.luau`;
to hear a sound, set `SoundId` (`rbxassetid://...`) there.

**Interface.** Player and target frames with round portraits (ViewportFrame), HP/mana/XP bars, a ring bar with a
radial cooldown and a quality-coloured frame, a cast bar (cast time is `CastTime` in the skill config, `0` = instant),
floating damage numbers and a level-up for killing enemies. Colours and sizes live in `ui/Theme.luau` and
`ui/Chrome.luau`. Icons are drawn in code; to use your own ring picture, set `Image = "rbxassetid://..."` in
`RingsConfig`. Fonts are built-in Roblox fonts (Merriweather, Fondamento, Nunito, Gotham) configured in
`shared/Fonts.luau`.

Inventory, mana and XP are currently kept in server memory (no DataStore): `InventoryService.serialize/load` is the
hook point for saving. Dummies take damage from `Tool` touches and respawn after 4 seconds.

## Ring Summon (Gacha), economy and Robux

**Model.** RNG-game style (like Sol's RNG): the pool is `Configs/Rings/RingsConfig.luau`; every ring has a base rarity
`OneIn` ("1 in N", up to 1 in 50,000,000 for the Divine Genesis Ring). A roll goes through the rings from the rarest
to the most common; each hits with `min(1, luck / OneIn)`; the most common ring takes the remainder. The same math
(`shared/Gacha/GachaMath.luau`) produces the odds table shown to the player, so the displayed chances are the real
ones and add up to exactly 100%. There is no pity system (not used in this genre). **Luck** = 1 + (ring luck + paid
luck) / 100, capped by `GachaConfig.Luck.Max`. Duplicates become Ring Essence. Epic or better finds can be announced
to everyone (`GachaConfig.Announce.MinOneIn`).

**Currencies.** Gold and Summon Crystals come from kills and level-ups (numbers in `GachaConfig.Rewards`), Ring
Essence from duplicates; a free roll is available every 20 hours. Rings give passive bonuses (damage, mana,
cooldown, range, luck) that are applied on the server and listed in the Character window.

**Saving.** `DataService` keeps the player profile in a DataStore. In Studio enable *Game Settings → Security →
Enable Studio Access to API Services*; otherwise data lives only in memory and real purchases are not confirmed.

**Robux.** Fill in the IDs in `Configs/MonetizationConfig.luau` after creating the Developer Products (crystal packs,
luck potions) and Game Passes (Auto Roll, Fast Roll, Lucky Charm) in the Creator Hub. Until an ID is set, the Store
shows "Not set up"; in Studio the "Test Grant" button gives items without Robux. `MonetizationService` owns the single
`ProcessReceipt`: purchases are idempotent by `PurchaseId` and are confirmed only after the profile is saved.

**Roblox "Paid Random Items" policy.** Random rewards bought with Robux (or with Robux-bought currency) must show all
outcomes with numeric odds in percent (summing to 100%) *before* purchase, explain paid luck boosts numerically, and be
disabled where `PolicyService` reports `ArePaidRandomItemsRestricted`. The Summon window's "Odds / Details" and the
Store's "View odds" cover the first two; for restricted players paid summons, paid luck and the paid Store items are
turned off and only the free roll remains. Review the current
[policy](https://create.roblox.com/docs/en-us/production/monetization/paid-random-items) before enabling real sales.

## Sounds

The two Arc Lightning sounds (`assets/audio/arc_lightning_charge.ogg` — cast charge, `arc_lightning_zap.ogg` —
impact crackle) are synthesized by `tools/make_audio.py` (re-run it to regenerate). Roblox can only play uploaded
assets, so upload them once:

1. `rokit add jacktabscode/asphalt` (adds [Asphalt](https://github.com/jackTabsCode/asphalt) to `rokit.toml`).
2. Put your Roblox UserId into `asphalt.toml` (`[creator] id`).
3. Create an Open Cloud API key with `asset:read` and `asset:write` permissions
   ([Creator Dashboard](https://create.roblox.com/dashboard/credentials)) and run
   `ASPHALT_API_KEY=<key> asphalt sync` (PowerShell: `$env:ASPHALT_API_KEY = "<key>"; asphalt sync`).
   Never commit or share the key.
4. Asphalt rewrites `src/shared/Assets.luau` and creates `asphalt.lock.toml` — commit both.

Alternative without Asphalt: import the files in Studio (Asset Manager → Bulk Import) and paste the
`rbxassetid://...` values into `Sounds.Manual` in `src/shared/Sounds.luau`. Until IDs exist the game stays silent.
Volume is `Config.Audio.SfxVolume` and `SoundVolume` in `ArcLightningConfig`.

## Lighting and atmosphere

All lighting numbers are in `Config.Lighting` (`src/shared/Config.luau`): ambient colours, fog, atmosphere, bloom,
colour correction, the moonlight shaft through the ceiling opening, and the torch colour/brightness. Warm light comes
only from braziers, lanterns and stalls; the cave itself is lit with cool blue light. Torch and lantern lights carry the
`Torch` tag and flicker on the client (`VFX/TorchFlicker.luau`).

## Switching from a local place

If the hub used to be generated by a script inside a Studio place (for example `ServerScriptService.Script`),
**delete the old script** before syncing: otherwise it overwrites the map on every run.

## Stalls

The stall model is loaded when the server starts via `InsertService:LoadAsset` (ID in `Config.StallAssetId`):
one tent is taken from the set, halved in size, stripped of scripts and `Fire`, and its stripes are recoloured to
yellow, blue, red and green. If loading fails, procedural stalls are built instead.
